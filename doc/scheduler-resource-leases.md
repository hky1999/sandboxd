# 调度器资源租约与准备失败的归属

沙箱的资源代际独立于资源池的物理名称。池化 cgroup 的路径、网络端点的 IP 和 ifindex 在再次租用后可能保持相同，旧清理操作不能依据这些值释放新所有者。本契约规定守护进程的租约条件与持久回收；调度器仍须另外核对原操作、sandbox ID 和资源代际，以及完整沙箱退役证明，才能归还预算。

## cgroup 的物理代际所有权

`CgroupManager.AllocateForGeneration` 将原始资源代际与分配路径一起写入 `config.CgroupBucket`，确认持久写入后才成功返回。持久写入失败返回原路径和错误，租约继续占用，不进入空闲池。共享创建流程记录这个已知路径，不把错误解释为没有分配。

`RecycleForGeneration` 要求原路径与资源代际匹配；没有匹配的活动所有权或完成记录时返回 `FailedPrecondition`。清理成功后，将活动租约移除及原代际完成记录写入同一事务，再允许路径回到空闲池。写入失败继续保留原活动租约。重复回收仅回放同一路径的原完成记录，即使路径已租给邻居，也不再次清理物理资源。无条件 `Recycle` 拒绝有代际所有权的租约。

日志 schema 为 2，记录活动路径、路径到代际的所有权及代际到原回收路径的完成记录。重启拒绝未知 schema、重复代际、同时活动与完成的代际，以及不属于本管理器的路径。旧日志没有所有权的活动租约保持未归属，不自动借用当前沙箱的代际；条件回收拒绝这类租约。升级前必须在旧匹配程序上确认本任务原执行与租约已经清理，或者开发独立的可证明归属迁移；不得清空数据库来绕过它。

活动所有权与完成记录合计最多 65536 项。满额拒绝新的代际分配，没有自动删除或过期回收。安全归档与容量回收仍待实现。

## 池化网络端点的每次租用身份

每次池化网络分配生成新的 UUID `NetResource.leaseID`，将完整序列化事实作为活动键，写入 `config.BridgeIpBucket` 后才成功交付。重启保留原活动身份，不按 IP 或 ifindex 重建一个新的身份。

池化 `Recycle` 在设备确认断开后，将活动键移除及原 leaseID 对完整原始序列化事实的 SHA256 完成记录写入同一事务，随后清除空闲条目的 leaseID 并允许复用。持久写入失败时保留原活动键，禁止加入空闲池。原租约的重复回收、断开或丢弃可以回读精确完成记录，不能匹配新所有者的活动键；活动记录缺失且没有原完成记录时返回 `FailedPrecondition`，任何变化的事实也不能借用完成记录。

网络租约日志 schema 为 2，活动键与池化完成记录合计最多 65536 项，没有自动删除。启动前校验 schema、UUID、指纹、重复活动身份及活动与完成的冲突。既有不带 leaseID 的活动资源维持旧的未归属语义，不能冒充新租约的完成证明。`Discard` 的完整销毁证明、临时 veth 与 namespace 的逐步清理及崩溃恢复仍待补齐；本契约不将这些路径写成已经完整验收。

## 部分准备失败

资源准备函数收集全部结果并按声明顺序返回错误，同时返回所有非空的已知租约，包括带错误的已知租约。该函数不自行回收资源。共享创建流程将部分资源事实写入原 INTENT 元数据；成功准备的文件系统登记原来源；随后保留物理意图、资源和已预留 ID，等待原代际的权威对账。

第一次物理元数据发布尝试之后，共享创建的全部错误路径保留现有原归属，包含运行时已经成功后的端口规则、提交或可见发布错误。初始发布可能已 rename 而目录同步报错，因此也保留预留 ID，不把错误解释为没有写入。物理意图对账在运行时不存在得到确认后，先断开已知原网络租约，再移除 ACL；任何错误都阻止后续资源回收。已提交但未发布的物理记录继续由原创建结果查询核对，不在失败返回路径上改写或删除。

这些条件覆盖函数返回之后可记录的已知归属。分配生效到元数据记录之间的崩溃窗口、分配结果完全未知、文件系统准备或提交失败后的归属、所有资源的逐步清理与目录删除确认，以及清理完成到沙箱退役回执发布之间的窗口仍待完成。资源租约完成记录只证明对应资源的回收，不是整个沙箱的完成退役回执。

本批验收范围是本地组件测试、实际数据库重开、代际条件和持久写入失败；真实宿主上的部署字节与故障矩阵仍须在 BareMetal1 单独验收。
