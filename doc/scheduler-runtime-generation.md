# 运行时资源代际的可信接线

服务器传给运行时的 StartConfig.ResourceGeneration 只取自原物理元数据。创建入口、通过创建入口的恢复以及独立恢复入口均重新取值；请求注解、设备提供者注解和源检查点不能成为新物理执行的代际。元数据属于另一沙箱时，在运行时派发前拒绝。没有原元数据的旧输入保持空值，不借用调用方传入的字段。

gVisor 的创建与恢复把这个字段传到同一份 StartArgs，并使用 OCI loader 的 ManagedAnnotations 在请求和设备字段之后写入 akernel.scheduler/resource-generation。空代际覆盖同名外部字段，不能通过伪造注解取得新管理语义。受管理创建先检查完整 bundle 注解、没有已有原生状态，以及私有原目录；返回后再次检查原生状态中的代际、容器 ID、sandbox ID、创建阶段和 bundle 路径。开始运行与恢复读取该状态后，在打开 TAP 或建立控制连接之前拒绝错代际、字段缺失或原 bundle 不符。

原生控制状态最多读取 8 MiB，必须是当前 daemon 所有、没有组或其他用户写权限、单硬链接的普通文件；通过原目录和 O_NOFOLLOW、O_NONBLOCK 读取并核对前后文件及目录身份，拒绝重复字段、尾随内容、FIFO、符号链接、损坏数据和不完整身份。读取器不再凭文件名采用另一个容器或另一个 sandbox 的控制 socket。创建取消在打开输出文件或启动程序之前返回。

受管理创建、开始运行或恢复的结果未知时，适配器不调用旧无条件 runsc delete，也不立即卸载可能仍被原执行使用的私有根目录。创建返回 ErrRuntimeCreationUnconfirmed，恢复返回 ErrRestoreCleanupIncomplete，保留物理意图和上层占用，等待原身份对账。旧没有代际的适配器输入保留原清理路径。

RuntimeGenerationVerifier 是只读拒绝条件。正常删除和失败创建对账在原元数据带代际时，先向实现该接口的运行时核验原生代际；缺失、读取失败或另一代际停止后续删除，不能保存完成或归还资源。永久公开入口用例保留原状态、物理意图、设备租约和创建 PENDING，并证明没有执行修改命令。

本批不提供完整进程出生证明或原子条件删除。匹配注解和 PID 数字仍不能证明对应进程的启动时间与实际程序；观察结束后到控制调用或 CLI 删除之间仍有替换窗口，现有上游删除还有数字 PID 信号路径。第一条生产端事实保存、Sentry／gofer 原进程记录、可信进程句柄、原进程退出确认和整个预算结算仍待实现和物理验收。只读核验接口不能被写成完整退役证书，原生状态缺失也不能被写成原执行从未存在。
