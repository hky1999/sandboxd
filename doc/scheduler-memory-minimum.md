# 调度器独立内存缩容下界

本轮源码候选支持独立缩容下界；当前部署、完整绿色检查和物理故障验收尚未完成。

普通新建仍使用原弹性策略的Memory.initial出生额度。旧版本1标签保持原语义，下界等于initial，不能携带新字段。新版本2标签必须携带正整数memory_minimum_mib，且不大于Memory.initial；Memory.ceiling仍为允许上限。CPU出生与允许上限的含义保持。

例如Memory.initial和Memory.ceiling均为2048、memory_minimum_mib为640时，普通Start的实际额度必须为2048MiB。条件资源操作和恢复的有效额度可以在640至2048MiB之间，不能低于持久下界；下界来自持久元数据和检查点策略，不从资源请求临时采用。

新字段由现有元数据和检查点路径完整保存，物理回读继续返回原策略标签。版本、单位、完整代际、资源修订号、原操作指纹、期限、冻结归属及最终解冻要求不放宽。旧程序会因未知字段或版本拒绝新策略，不能回退为旧的无条件操作。
